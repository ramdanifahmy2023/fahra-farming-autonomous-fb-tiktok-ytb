# Font hook

`BarlowSemiCondensed-Bold.ttf` diambil tanpa modifikasi dari [Google Fonts](https://github.com/google/fonts/blob/main/ofl/barlowsemicondensed/BarlowSemiCondensed-Bold.ttf), 16 Oktober 2026.

- Pemilik hak cipta: The Barlow Project Authors (2017).
- Lisensi: [SIL Open Font License 1.1](OFL.txt), wajib ikut distribusi.
- Ukuran: 111772 byte.
- SHA-256: `5bd6757e459a110da81b44532f0f43058e2dab2401688abca84f2fdbde193cbb`.

Font dipilih untuk bentuk tebal yang tetap ringkas pada video vertikal. Kebijakan biner di `scripts/verify.py` mencocokkan path dan hash persis, termasuk isi index Git.
